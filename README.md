# `aslfun`

Scuffed ASL parsing, derived from parts in [`alehed/aslutils`](https://github.com/alehed/aslutils).

This repository does not track `.asl` files. 
These scripts expect that you've used 
[`alastairreid/mra_tools`](https://github.com/alastairreid/mra_tools) and 
placed `arch_decode.asl` in the project root.
